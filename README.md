# Mini-app Perfil de estudiante

Práctica básica de Android desarrollada con Java y vistas XML.

## Funcionalidades

- Formulario con nombre, matrícula y carrera.
- Validación de campos obligatorios.
- Botón para guardar el perfil.
- Segunda pantalla con el resumen del estudiante.
- Mensaje Toast al guardar correctamente.

## Cómo ejecutar

1. Abrir el proyecto en Android Studio.
2. Esperar a que Gradle termine de sincronizar.
3. Ejecutar la aplicación en un emulador o dispositivo Android.
